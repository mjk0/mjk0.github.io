Stronger robots (new game only)

Empty seats and solo tables get a tougher opponent in the new lobby and table. In our testing, the new robots score about +8 points per game on average versus the classic ones. Robots in the original game are unchanged — the upgrade is only in new lobby / table play.

Try it

  2. Create a private table, or sit at a public one
  3. Notice White/Red seating, then Start when ready
  4. Leave seats empty (or sit solo) — robots fill them
  5. At the table: lobby side panel · +N · rank strip (dismissible)
